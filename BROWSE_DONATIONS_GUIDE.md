# Browse Available Donations - User Guide

## Feature Already Implemented!

The Browse Available Donations page is fully functional and shows all available donations with images.

## How to Access

### Method 1: From Dashboard
Dashboard → Click "Browse Items" button

### Method 2: From Navigation Menu
Top Navigation → Click "Browse" link

### Method 3: Direct URL
http://localhost:5000/donations

## Page Features

### 1. Search and Filter
- Search bar - Search by item name
- Category filter - Filter by category (Clothing, Food, Books, Electronics, etc.)

### 2. Donation Cards Display

Each donation card shows:
- Item image (200px height)
- Item name and status badge
- Category and condition
- Description preview
- Donor information (name, address, contact)

### 3. Visual Indicators

Your Own Donations:
- Blue border (2px solid)
- "Your Donation" badge at top
- Clearly marked

Others Donations:
- Standard white card
- Clickable to view details

### 4. Grid Layout
- 3 columns on desktop
- Responsive design
- Clean, modern cards

## What Shows on This Page

### Included:
- Available donations (green badge)
- Requested donations (yellow badge)
- All donation images
- Donor contact information
- Search and filter options

### Excluded:
- Donated items (automatically hidden)
- Items marked as completed

## Click on Any Card

When you click a donation card:
1. Opens detailed view
2. Shows full description
3. Shows donor contact details
4. Shows "Send Request" button (if not yours)
5. Shows "Your Donation" message (if yours)
